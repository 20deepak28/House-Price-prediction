# 🏠 House Price Prediction

A machine learning web application that predicts house prices based on property details provided by the user. The project uses a Linear Regression model trained on housing data and delivers instant predictions through a simple and interactive Flask-based web interface.

---

## 🚀 Features

- Predict house prices in real time
- Interactive and easy-to-use web interface
- Machine Learning model built with Scikit-learn
- Flask backend for handling predictions
- Fast and reliable performance

---

## 🛠️ Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy

- JavaScript

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/20deepak28/House-Price-prediction.git
```

### Navigate to the project directory

```bash
cd House-Price-prediction
```

### Install the required dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000/
```

---

## 📈 How It Works

1. Load and preprocess the housing dataset.
2. Train a Linear Regression model using Scikit-learn.
3. Accept user inputs through the web interface.
4. Pass the inputs to the trained model.
5. Display the predicted house price instantly.
